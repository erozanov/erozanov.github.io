# Публикация заметок из Obsidian в блог

Ранбук для агента (kimi-claw / Kimi Code) и для человека. Цель: из заметки в Obsidian
с фотографиями получить опубликованную страницу блога с минимумом действий автора.

## Роли

- **Агент в Telegram (kimi-claw)** — принимает заметку, готовит её по шагам ниже,
  кладёт в папку готовых к публикации в vault.
- **Скрипт на Mac** (`scripts/publish-note.mjs`) — всё механическое: сжатие фото,
  загрузка в хранилище, создание файла заметки блога, git push.
- **GitHub Actions** — деплоит сайт после пуша.

## Формат подготовленной заметки

Агент создаёт в vault рядом с исходной заметкой (или в папке `Публикации/`) файл вида:

```markdown
---
status: готово
trip: china            # id поездки = имя файла в src/content/trips, или её название
city: Санья            # название города как в frontmatter поездки
title: Вода невероятного цвета
date: 2026-10-13       # YYYY-MM-DD
tags: море, утро       # опционально, через запятую
best: IMG_4312.jpg     # опционально — файл лучшего кадра (попадёт в «Лучшие кадры»)
---

Свободный текст заметки. Поддерживается обычный markdown.

![[IMG_4312.jpg]]
![[IMG_4313.jpg|Подпись к фото — станет alt-текстом]]
![[video_1013.mp4]]
```

Правила подготовки (за агентом):

1. Все вложения — **файлы рядом с заметкой** (Obsidian Sync доставит их на Mac).
2. `trip` и `city` обязательны. Если поездки или города нет в блоге — не гадать:
   сказать пользователю, что нужно создать поездку (нужны координаты города),
   либо добавить город в существующую.
3. Дату брать из заметки или EXIF; если неясно — спросить одним сообщением.
4. `status: готово` ставить только когда всё заполнено.

## Публикация (на Mac)

```bash
node scripts/publish-note.mjs "/путь/в/vault/Публикации/2026-10-13-вода.md"
```

Скрипт: проверит поля → найдёт поездку и город → сожмёт фото до 2000px →
положит медиа в `public/media/<поездка>/<город>/` (или в R2, если заданы
`PUBLISH_TARGET=r2`, `R2_BUCKET`, `R2_PUBLIC_URL`, `CLOUDFLARE_API_TOKEN`) →
создаст `src/content/moments/<поездка>-<дата>.md` → закоммитит и запушит
(деплой ~1 минута) → допишет в исходную заметку `status: опубликовано` и URL.

Флаг `--no-push` — всё сделать локально без коммита (для проверки).

## Чего скрипт НЕ умеет (и не должен угадывать)

- Создавать поездки и города — нужны `coordinates`; попросите агента блога
  или добавьте вручную в `src/content/trips/<поездка>.md`.
- Сжимать видео (нужен ffmpeg) — копирует как есть. Большие ролики сжимайте
  заранее: `ffmpeg -i in.mov -vf scale=1280:-2 -crf 28 out.mp4`.
