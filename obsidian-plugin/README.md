# Плагин Obsidian для блога «Следом»

Плагин позволяет публиковать и обновлять поездки и моменты в блоге прямо из Obsidian одной кнопкой или горячей клавишей.

---

## 🚀 Установка в Obsidian

Внутри вашего хранилища (Vault) Obsidian есть скрытая папка конфигурации `.obsidian/plugins/`.

1. Откройте терминал и создайте символическую ссылку (symlink) на плагин в ваш Vault:
   ```bash
   # Замените "/Путь/К/Вашему/Vault" на реальный путь к хранилищу Obsidian:
   mkdir -p "/Путь/К/Вашему/Vault/.obsidian/plugins"
   ln -s /Users/erozanov/Projects/travel_blog/obsidian-plugin "/Путь/К/Вашему/Vault/.obsidian/plugins/sledom-blog"
   ```
   *(Или просто скопируйте папку `obsidian-plugin` как `sledom-blog` в `.obsidian/plugins/`)*

2. В Obsidian:
   - Откройте **Settings** (Настройки) → **Community plugins** (Сторонние плагины).
   - Если включён Restricted mode — отключите его.
   - Нажмите **Reload plugins** (Перезагрузить установленные плагины).
   - В списке появится **Следом Blog** — включите его переключателем.

3. В настройках плагина (Следом Blog в левом меню настроек) убедитесь, что путь к репозиторию указан верно:
   `/Users/erozanov/Projects/travel_blog`

## 🧭 Как пользоваться

### 1. Планирование новой поездки
1. Создайте в Obsidian заметку поездки (например, `Япония.md`).
2. Нажмите `Cmd + P` → выберите команду:  
   **`Следом: Вставить шаблон новой поездки (mode: trip)`**.
3. Заполните города, координаты и даты:
   ```markdown
   ---
   mode: trip
   status: готово
   id: japan
   title: Япония
   country: Япония
   number: "005"
   startDate: 2027-03-10
   endDate: 2027-03-24
   summary: "Токио, Киото и пять дней без плана"
   cover: japan-hero.jpg
   coverAlt: "Вид на Токио с горой Фудзи"
   featured: false
   ---

   Вводный текст поездки...

   ```cities
   Токио | tokyo | 35.6762 | 139.6503 | Мегаполис, который никогда не спит | tokyo.jpg | Ночной Токио
   Киото | kyoto | 35.0116 | 135.7681 | Старый город, храмы и сакура | kyoto.jpg | Кинкакудзи
   ```
   ```
4. Положите файлы обложки (`japan-hero.jpg`, `tokyo.jpg` и т.д.) рядом с заметкой в Vault.
5. Нажмите иконку **компаса** на панели слева или `Cmd + P` → **`Следом: Опубликовать / обновить активную заметку в блоге`**.
6. Плагин обработает медиа, создаст файл в блоге, закоммитит и запушит в GitHub.

### 2. Обновление поездки
Если вы скорректировали текст, даты или добавили город:
- Просто снова нажмите иконку **компаса** (или команду публикации).
- Плагин спросит подтверждение и обновит поездку на сайте.

### 3. Публикация моментов
Моменты (заметки с фото из путешествия) публикуются точно так же:
```markdown
---
status: готово
trip: japan
city: Токио
title: Первое утро в Токио
date: 2027-03-11
tags: город, утро
---

Текст заметки...
![[IMG_1234.jpg]]
```
Нажимаете кнопку публикации — момент отправляется на сайт!

## 🛠 Пересборка плагина (для разработчиков)

Если менялся исходный код плагина в `src/`:
```bash
npm run build:plugin
```
Скомпилированный бандл запишется в `obsidian-plugin/main.js`.
